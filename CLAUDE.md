# Testrill contributor context

Read and follow [AGENTS.md](AGENTS.md), then [CONTRIBUTING.md](CONTRIBUTING.md). Those files are the shared source of contributor instructions; this file does not define a different workflow for one coding client.

For using Testrill to test another application, read [agent integration](docs/agents.md) and the [testing skill](.agents/skills/testrill/SKILL.md). Keep assertion results distinct from screenshots and from a merely started run.
