# Code of conduct

Testrill welcomes contributors with different backgrounds and levels of experience. Help others participate by making feedback specific, constructive, and respectful.

- Discuss behavior and technical decisions without personal attacks.
- Be patient with questions and acknowledge corrections.
- Respect people's identities, boundaries, time, and privacy.
- Do not harass, threaten, discriminate, disclose private information, or repeatedly contact someone who has asked you to stop.
- Keep issues and pull requests relevant to the project. Do not post spam or promote unrelated services.

These expectations apply in repository issues, pull requests, Discussions, reviews, and other project spaces. Maintainers may edit or remove content, close a conversation, or restrict participation when needed to protect the community. They should explain moderation decisions where doing so does not disclose private information.

For a project moderation concern, contact the maintainer using a contact method they list on [their GitHub profile](https://github.com/tedy69). If no suitable private channel is listed, ask for a private contact without publishing incident details or identifying information. GitHub's **Report abuse** flow is another private reporting route; those reports go to GitHub, not to the project maintainer. Use the [security policy](SECURITY.md) for software vulnerabilities.
