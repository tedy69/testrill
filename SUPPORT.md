# Getting help

Start with the [documentation index](docs/README.md), [troubleshooting guide](docs/troubleshooting.md), and [verified scope](docs/verification.md).

| Need                                        | Where to go                                                                                        |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Setup, agent integration, or usage question | [GitHub Discussions](https://github.com/tedy69/testrill/discussions)                               |
| Reproducible defect                         | [Bug report form](https://github.com/tedy69/testrill/issues/new?template=bug_report.yml)           |
| Feature or adapter proposal                 | [Feature request form](https://github.com/tedy69/testrill/issues/new?template=feature_request.yml) |
| Contribution or review workflow             | [Contributing guide](CONTRIBUTING.md)                                                              |
| Vulnerability                               | [Private security reporting](SECURITY.md)                                                          |
| Community concern                           | [Code of conduct](CODE_OF_CONDUCT.md)                                                              |

For technical help, include the commit/version, OS and architecture, Node version, runner/client name when relevant, exact command or UI action, expected result, and a minimal manifest with synthetic data. Remove tokens and application data from logs and screenshots. A saved run ID is useful context, but other people cannot open a run ID stored only on your computer.

Support is community-based and best effort. No paid support service or response-time commitment is offered by this repository.
